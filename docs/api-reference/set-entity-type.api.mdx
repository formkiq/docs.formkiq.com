Sets an entity type.

Existing PRESET entity type names cannot be changed, including when
createIfMissing=true. CUSTOM entity types can be renamed.

Requires WRITE_RETENTION_POLICY for the PRESET RetentionPolicy type,
WRITE_REMINDER_POLICY for the PRESET ReminderPolicy type, or WRITE_ENTITY
for other types. The dedicated preset permission replaces the generic entity
permission; WRITE_ENTITY alone does not authorize either dedicated preset.
Existing types use their stored namespace and name. When creating a missing
type, the namespace and name in the request body determine the permission.
Updating an existing type must not bypass its current permission requirement.
