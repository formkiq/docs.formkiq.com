Returns an entity.

Requires READ_RETENTION_POLICY for the PRESET RetentionPolicy type,
READ_REMINDER_POLICY for the PRESET ReminderPolicy type, or READ_ENTITY
for other types. The dedicated preset permission replaces the generic entity
permission; READ_ENTITY alone does not authorize either dedicated preset.
The preset is identified by its stored namespace and name, whether the request
identifies the entity type by name or UUID. A CUSTOM type with the same name
continues to use the generic entity permission.
