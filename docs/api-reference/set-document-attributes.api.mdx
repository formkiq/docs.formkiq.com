<MethodEndpoint
  method={"put"}
  path={"/documents/{documentId}/attributes"}
  context={"endpoint"}
>
  
</MethodEndpoint>



Set multiple attributes to a document; this endpoint also accepts a different body parameter for setting a single attribute

Note:
- attributes in the request will overwrite existing attributes.
- jsonValue replaces the entire JSON object; nested fields are not merged.

Requires WRITE_DOCUMENT_ATTRIBUTES or WRITE. ADMIN retains access.
