# FormKiQ Web v4.3.8

## Release Summary

FormKiQ Web (Document Console) v4.3.8 adds browser-based email previews and PDF exports, resizable document information panels, background uploads, and multilingual interface customization. The web application includes twelve locale choices, Arabic right-to-left layout, light and dark themes, and keyboard navigation for common pages and document actions.

The release also improves search on installations without a full-text engine, document-list feedback, accessibility, session recovery, and authentication security. The [Contract Management Business Solution](/docs/business-solutions/contract-management) adds coordinated lifecycle transitions and cancellation of an entire review by an authorized assigned reviewer.

Web releases have their own versions and can ship between API and backend releases. Contract Management web changes share this web release version.

## Platform Compatibility

| Area | Compatibility |
|------|---------------|
| Backend distribution | [FormKiQ v1.19.2](/docs/changelog/v1.19.2) bundles Web v4.3.8. Web and backend version numbers are independent. |
| API Explorer | This web release includes the v1.19.2 API specification. Available operations still depend on the connected backend and permissions. |
| Global interface translations | Automatic inheritance requires a backend that advertises scoped global locale reads. Global editing remains hidden on unsupported APIs; workspace translation overrides and administrator copy operations have separate behavior described below. |
| Business Solutions | Contract Management requires the licensed solution and its configured backend services and permissions. |

The bundled version identifies a documented pairing. It does not establish a minimum backend version for every web feature. Before updating a deployment using an earlier backend, check the APIs and capabilities required by the features you use.

## Upgrade Notes

- Building FormKiQ Web from source now requires Node.js 24 or later and npm 11.
- Automatic inheritance of global interface translations requires a compatible API that advertises scoped global locale reads. Global editing remains hidden on unsupported APIs. Administrator **Copy to all workspaces** works independently and preserves existing workspace overrides unless replacement is explicitly confirmed.
- Document sorting and administrative list filters apply to loaded items. Background uploads and bulk operations run in the browser session; they do not continue after the browser session closes. Recoverable editor drafts are stored in the current browser tab, rather than saved to the server.
- Email preview supports source files up to 25 MB, bodies up to 5 MB, and up to 200 attachments. Generated PDFs list attachments without merging their contents. RTF-only MSG messages use a plain-text fallback.
- In Contract Management, review cancellation restores the saved pre-review lifecycle state. Older review cycles without a saved baseline use the fallback shown in the confirmation. Lifecycle coordination supports retries after partial failures but is not a server-side atomic transaction.

## Web Application

### Features

- #1285 Added MSG and EML previews with formatted email headers and bodies, embedded images, original-message and attachment downloads, and PDF preview and download generated in the browser. No Document Generation module or backend conversion service is required.
- #1286 Added resizable information panels for documents and dossiers, with mouse, touch, and keyboard controls, width limits, and reset controls.
- #1289 Added twelve built-in locales: English, French (Canada), Italian, German, Spanish (Spain), Spanish (Latin America), Portuguese (Portugal), Portuguese (Brazil), Dutch, Traditional Chinese (Hong Kong), Japanese, and Arabic. Arabic uses right-to-left layout while preserving the reading direction of filenames, paths, and identifiers.
- #1289 Added searchable interface translation catalogues, workspace-specific wording overrides, JSON-based deployment overrides, and export of resolved locale catalogues. Administrators can preview copying custom translations to all workspaces, with replacement warnings and backups when overwriting matching overrides.
- #1288, #1289 Added Light, Dark, and System appearance options and remembered preferences for sidebar state, information-panel width, list density, and search type. Custom brands default to Light unless a preference has been saved.
- #1288 Added **Ctrl/Cmd+K** quick jump for pages, folders, and document actions, plus **/** to focus document search.
- #1288, #1289 Added an **Upload in background** option and a minimizable background-operations panel with progress, item and byte counts, cancellation, and completion feedback. Bulk operations also report progress, and supported document moves offer guarded undo.
- #1288 Added workflow-designer undo and redo, local draft recovery for workflows, rules, and LLM prompts, unsaved-change guards, and session-expiry warnings with a renewal action.

### Updates

- #1288 Added non-blocking toast notifications, inline validation for common form errors, severity styling, and clearer destructive confirmations that identify the target and action.
- #1288 Added sorting within loaded document rows, loaded and selected counts, end-of-folder feedback, skeleton loading rows, and actionable empty states.
- #1288 Added route-level error recovery and retry actions, and distinguished failed document loads from genuinely empty folders. Replaced placeholder help content with documentation links.
- #1288, #1289 Improved focus indicators, form labels, accessible tooltips, metadata contrast, sidebar spacing, nested-folder indentation, and custom branding in light and dark themes. Added transparent white logo assets for dark backgrounds.
- #1289, #1294 Added relative document dates with accessible exact-date tooltips showing seconds, UTC offset, and timezone. Date tooltips remain above sticky table headers.
- #1287 Expanded API Explorer coverage for the v1.19.2 API specification, including the permissions catalogue, OPA policy tests, DocuSign audit events, and document and search request inputs.

### Bug Fixes

- #1291 Fixed standard search on installations without Typesense or OpenSearch to use filename-prefix search for plain text. Fixed keyboard result selection, cross-route search focus, and encoding of queries containing characters such as `&` and `#`.
- #1288, #1291 Fixed file and folder upload actions outside the Documents area, clarified preservation of uploaded folder paths, and prevented newly uploaded files from appearing to have zero size while server metadata catches up.
- #1287 Fixed tag edits to use current document state for top-level and nested documents, including removing a tag when its final value is deleted.
- #1294 Fixed document checkbox IDs and accessible names, date-tooltip opacity, and narrow-screen layouts where search, counts, or selection controls could overlap.
- #1289, #1294, #1295 Fixed stale labels after changing languages, translated dynamic upload and validation feedback, and localized the new-item submit button and singular/plural bulk-trash and permanent-delete action labels. Preserved legacy locale identifiers and separate schema/classification locale resources.
- #1291 Fixed empty locale-copy previews to explain when there are no workspace customizations to copy, without performing writes.

### Security

- #1288 Updated vulnerable rendering, editor, routing, and build dependencies, including DOMPurify, PDF.js, the DOCX editor, and React Router.
- #1288 Added one-time OAuth state validation and PKCE, and strengthened validation of authentication redirects and deep-link destinations.
- #1285 Sanitized and sandboxed email HTML, blocked remote email resources, and bounded email parsing and PDF generation to reduce exposure to active content and tracking requests.
- #1288, #1289 Isolated background-task history, translation requests, and editor drafts across account and workspace changes. Running uploads are cancelled when the signed-in account changes.

## Business Solutions

### Contract Management

These changes are delivered in the Contract Management web workspace. See the [solution guide](/docs/business-solutions/contract-management) for the agreement workflow and supporting configuration.

#### Features

- #1283 Added previewed, audited lifecycle transitions that coordinate review work, signing state, reminders, and related agreements before publishing a new status. Completed steps are checkpointed so interrupted operations can be retried.
- #1284 Added cancellation of an entire review by an authorized assigned reviewer, with a required reason and confirmation. Cancellation closes review work, clears pending assignments and tasks, preserves document and package history, and restores each agreement's pre-review state.

#### Updates

- #1283 Required signature evidence or documented exceptions when activating an agreement outside the normal review and signing workflow. Sent or delivered envelopes require explicit confirmation before voiding; unsent drafts can be retired locally while remaining in DocuSign.
- #1284 Enabled review cancellation by default for Business Review through `businessReviewMayCancelReview`, with per-step configuration through `allowCancelReview`. Cancellation requires workspace write permission, reviewer assignment, and applicable approval-group authorization.

#### Bug Fixes

- #1283, #1284 Protected completed lifecycle steps and cancelled review cycles from stale Console updates, preserved each combined-review member's baseline, and prevented retired signing bindings from being revived through Console callbacks.

## Known Issues

- The Trash navbar title can still display the English word **Trash** in Arabic. Translated confirmation and Restore controls remain available.
- Bundled translations may require native-speaker review for organization-specific terminology. Workspace and JSON overrides can be used to customize the wording.
